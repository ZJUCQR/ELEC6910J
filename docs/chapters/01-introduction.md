# 1: Introduction

<p class="chapter-subtitle">导论 · 从预测到决策</p>

**主要内容**：学习范式、理性智能体、强化学习交互过程与应用。

## 1.1 Rational Agents（理性智能体）

- Artificial Intelligence（人工智能）：课件从“像人一样思考／行动”和“理性地思考／行动”两个维度介绍 AI。
- Agent（智能体）：能够感知环境并采取行动的实体。
- Rational Agent（理性智能体）：根据已有信息，选择使 **Expected Utility（期望效用）最大**的行动。
- 决策的好坏取决于结果的概率及其效用。一次行动碰巧成功，并不说明它在决策时就是最合理的选择。

$$
a^*=\arg\max_a \sum_s P(s\mid a)U(s)
$$

这里 $P(s\mid a)$ 表示采取动作 $a$ 后出现结果 $s$ 的概率，$U(s)$ 表示该结果的效用。后续强化学习把这一目标推广到**连续多步交互的累计奖励**。

### 1.1.1 PEAS（任务描述）

PEAS 用四个部分描述智能体的任务：Performance measure、Environment、Actuators、Sensors。

!!! example "原课件例子：Taxi Driver（出租车司机）"

    | 部分 | 含义 | 课件中的例子 |
    | --- | --- | --- |
    | Performance measure | 如何衡量表现 | 安全、快速、舒适、利润 |
    | Environment | 在什么环境中行动 | 道路、其他车辆、行人、乘客 |
    | Actuators | 如何影响环境 | 方向盘、油门、刹车、转向灯、喇叭 |
    | Sensors | 如何获得信息 | 摄像头、声呐、车速计、GPS、里程计等 |

    先区分“能观察到什么”和“能控制什么”，再讨论应该采用什么策略。例如，摄像头给出观察，方向盘执行动作；“安全”则属于评价标准。

{{ slide lec01-02 13 | PEAS：用出租车任务区分目标、环境、动作与观察 }}

### 1.1.2 Environment Properties（环境性质）

| 维度 | 含义 |
| --- | --- |
| Fully / Partially Observable | 能否观察到决策所需的完整状态 |
| Deterministic / Stochastic | 相同状态与动作是否产生确定结果 |
| Static / Dynamic | 决策过程中环境是否继续变化 |
| Discrete / Continuous | 状态、动作是否为离散取值 |
| Single / Multi-agent | 是否有其他参与决策的智能体 |

这些性质会影响问题建模。出租车通常面对动态、部分可观测、多智能体的环境；不能把它当作每次动作都按计划执行的静态迷宫。

## 1.2 Machine Learning（机器学习）

课件采用的核心观点是：程序通过经验 $E$，在任务 $T$ 上提高由指标 $P$ 衡量的表现。

### 1.2.1 Supervised Learning（监督学习）

给定带标签的数据集：

$$
\mathcal D=\{(x^{(i)},y^{(i)})\}_{i=1}^{n}
$$

学习从输入 $x$ 到输出 $y$ 的映射，并希望它能推广到未见过的数据。

- Regression（回归）：预测连续数值，如房价、行程时间。
- Classification（分类）：预测离散类别，如垃圾邮件、数字类别。
- Feature（特征）：模型用于判断的输入属性；特征可以人工设计，也可以由网络学习。

!!! example "原课件例子：房价、垃圾邮件与手写数字"

    - **房价预测**：输入房屋面积，输出价格；是回归问题。
    - **Spam Filter**：输入邮件，输出 spam / ham；词语、大小写、发件人是否在通讯录等都可能成为特征。
    - **Digit Recognition**：输入图像，输出 0–9；像素、长宽比、闭环数量等都能提供分类信息。

    三个问题都需要标签。即使模型输入的是图片，任务也要由输出类型判断：预测数字类别是分类，预测价格是回归。

### 1.2.2 NLP & Computer Vision（语言与视觉）

- Natural Language Processing（自然语言处理）：包括语音识别 ASR、语音合成 TTS、机器翻译、问答、对话和文本分类。
- Computer Vision（计算机视觉）：包括图像分类、目标定位、目标检测、人脸识别和场景分割。
- 图像分类的标签通常是类别；目标检测还要预测 Bounding Box（边界框），输出结构更复杂。
- 课件同时展示 ChatGPT、自动驾驶和 Stable Diffusion，说明机器学习应用的范围。它们涉及多种学习方法，不能因为出现在这一节就把整个系统都视为单一监督学习任务。

{{ slide lec01-02 25 | 目标检测：输出不仅有类别，还包括物体的位置 }}

### 1.2.3 Unsupervised Learning（无监督学习）

数据只有输入 $\{x^{(i)}\}_{i=1}^{n}$，没有逐条给定的目标标签。任务是发现数据中的结构，如聚类和表示学习。

!!! example "原课件例子：Word Embeddings（词向量）"

    用向量表示词语，用向量空间中的方向表达某些语义关系。这里要关注的是表示中捕捉到的结构，而不是为每个词手工指定一个类别标签。

{{ slide lec01-02 29 | 词向量：把词语及其关系表示在向量空间中 }}

## 1.3 Reinforcement Learning（强化学习）

强化学习通过智能体与环境交互，学习使**期望长期回报最大**的策略。

一次交互可写为：

$$
S_t \xrightarrow{A_t\sim\pi(\cdot\mid S_t)}
(R_{t+1},S_{t+1})
$$

- State $S_t$（状态）：当前决策所依据的环境描述。
- Action $A_t$（动作）：智能体的选择。
- Reward $R_{t+1}$（奖励）：环境对这次交互给出的标量反馈。
- Policy $\pi(a\mid s)$（策略）：在状态 $s$ 下选择动作 $a$ 的概率。
- Return（回报）：从当前时刻起累计、通常带折扣的奖励。

{{ slide lec01-02 40 | 强化学习交互：策略选动作，环境返回奖励和下一个状态 }}

### 1.3.1 与监督学习的区别

| 方面 | 监督学习的典型设置 | 强化学习 |
| --- | --- | --- |
| 学习信号 | 输入对应的目标标签 | 动作之后的奖励 |
| 数据来源 | 给定的数据集 | 与环境交互产生的经验 |
| 决策影响 | 通常不改变之后的输入 | 动作可能改变未来状态和数据 |
| 目标 | 减小预测误差 | 增大期望累计奖励 |

奖励并不直接告诉智能体“正确动作是什么”。有些动作要过很多步才显现价值；智能体还需要主动尝试，才能知道未选动作的效果。

### 1.3.2 Plan 与 Policy

- Plan（计划）：一串预先给定的动作。
- Policy（策略）：告诉智能体在**每个可能遇到的状态**下如何行动。
- 随机环境中，实际结果可能偏离计划，因此需要根据新状态重新选择动作。

!!! example "原课件例子：Stochastic GridWorld（随机网格世界）"

    选择 North 时，80% 的概率向北，10% 向西，10% 向东；若目标方向有墙，就留在原地。每步有 living reward，到达出口可能获得正奖励或负奖励。

    即使连续选择相同动作，也可能走出不同路径。因此，策略需要处理偏移后的状态。第 4 章将把这一例子写成 MDP，第 6 章再用价值迭代求解。

## 1.5 本章检查

- 能否用 PEAS 完整描述一个决策任务？
- 是否区分了“奖励”与“回报”、“动作序列”与“策略”？
- 遇到新问题时，能否判断数据是标签、无标签样本还是交互经验？
- 为什么随机环境中的最短路径，不一定对应最大期望回报的策略？

??? success "参考答案"

    1. **PEAS**：分别写清评价标准、环境、执行器与传感器。出租车的评价标准是安全、快速、舒适与利润；环境包括道路、车辆、行人与乘客；执行器是方向盘、油门、刹车等；传感器包括摄像头、车速计与 GPS。目标、可控制的量和可观察的信息应分开描述。
    2. **奖励与回报**：奖励 $R_{t+1}$ 是一步反馈，回报 $G_t=\sum_{k\geq0}\gamma^kR_{t+k+1}$ 是未来奖励的折扣累计，回合任务只累加到终止。**动作序列与策略**：动作序列预先列出要做的动作；策略根据当前状态选择动作或给出动作概率，能对随机结果作出不同反应。
    3. **判断学习方式**：输入与目标标签成对提供，如图片及类别，是监督学习；只有样本、需要发现结构，如无标签样本聚类，是无监督学习；智能体选择动作并获得奖励与后继状态，是强化学习。奖励评价行动后果，不等同于逐步给出正确动作的标签。
    4. **最短路径未必最优**：距离没有单独体现失败概率、惩罚或时间折扣。取 $\gamma=1$，某短路有 $0.8$ 概率获得 $10$、$0.2$ 概率获得 $-20$，期望回报为 $0.8\times10+0.2\times(-20)=4$；若较长路线确定获得 $6$，后者的期望回报更高。
